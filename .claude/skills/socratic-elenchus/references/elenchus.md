# Elenchus: method, framework, techniques

## 1. The Socratic method

In Plato's early ("aporetic") dialogues — *Euthyphro* (piety), *Laches* (courage), *Charmides* (temperance), *Meno* (virtue), *Republic* I (justice) — Socrates does not assert a definition. He asks for one, then tests it until it collapses. The typical sequence:

1. **"What is X?"** — the interlocutor offers examples or a definition.
2. **Refutation (*elenchus*)** — Socrates derives a consequence the interlocutor rejects, or produces a case the definition mishandles.
3. **Aporia** — the definition is abandoned; the interlocutor is now aware of not knowing.
4. **Retry** — a revised definition is offered, or the inquiry continues.

Two features matter for a reasoning skill:

- The **interlocutor supplies the definition**; the questioner only tests it. This keeps the exchange non-coercive and surfaces *their* commitments.
- The outcome is often **negative** (aporia). That is a legitimate deliverable: knowing that a term is undefined is progress. For practical work, this skill adds a constructive step — a revision and an operational test — so the chain ends in something usable rather than silence.

Socrates' disavowal of knowledge ("I know that I do not know") is also a methodological stance: probe from the definition offered, not from a preferred answer.

## 2. The four moves in detail

### Move 1 — Elicit the definition

Record it verbatim. Then classify:

| Type | What it is | Example | Test to apply |
|---|---|---|---|
| Ostensive | Defined by pointing or examples | "Engagement is things like likes and shares" | Does the example set have a common feature? |
| Reportive / lexical | Reports actual usage | "Fair means treating equals equally" | Is it too broad or too narrow vs. usage? |
| Stipulative | A decision to use a term a certain way | "For this contract, 'day' means a calendar day" | Is it consistent and useful? Not true/false. |
| Persuasive | Definition embeds a value judgment | "Reform means destroying what works" | Does the definition pre-decide the conclusion? |

Also note the **job** the term does: is it a goal ("increase engagement"), a criterion ("a fair process"), a category ("a recession"), or a causal claim ("stress causes illness")? The job sets how much precision is needed.

### Move 2 — Counterexample

The core test. Ennis's classic adequacy criteria for a definition:

- **Not too broad**: it admits things that are not X.
- **Not too narrow**: it excludes things that are X.
- **Not circular**: the definiens does not presuppose the definiendum.
- **Not obscure or figurative**: no metaphor standing in for criteria.
- **Not emotive**: no persuasive loading in place of criteria.

Practical probe types:

| Probe | Question | What failure it catches |
|---|---|---|
| False positive | "What satisfies the definition but is clearly not X?" | Too broad |
| False negative | "What is clearly X but fails the definition?" | Too narrow |
| Boundary case | "Give a case reasonable people would split on. What exactly divides them?" | Missing criterion |
| Scaling case | "Double the quantity. Does X double, plateau, or vanish?" | Category error (X is not a quantity) |
| Degenerate case | "What about zero, negative, or the extreme case?" | Unhandled limits |
| Contrast case | "What is the nearest non-X? What is the minimal difference?" | Missing differentiator |
| Substitution (salva veritate) | "Replace the term by its definition in the original sentence. Does the claim still mean the same thing?" | Definition does not fit the use |

### Move 3 — Revision

Repair strategies, in preference order:

1. **Disambiguate** — split into X₁ and X₂ with separate definitions; state which the argument needs.
2. **Narrow** — add the missing differentiator that excludes false positives.
3. **Widen** — drop or relax the clause that excluded real cases.
4. **Re-categorize** — the term was a process, not a state (or a judgment, not a property); fix the genus.
5. **Abandon** — if no revision survives the cases, the term is doing rhetorical work only. Say so.

A revised definition is well-formed when it has: a **category** (genus), a **differentiator** (what separates X from nearby members of the category), and at least one **checkable clause**. "Engagement is a behavioral state in which a user deliberately invests effort in the product, evidenced by repeat voluntary use within 30 days" has all three; "engagement is users liking the product" has none.

### Move 4 — Operational definition

An operational definition ties the term to a procedure and an observable outcome (the idea descends from Bridgman-style operationalism and measurement theory, not from Plato). Checklist:

1. **Indicator** — which observable event counts as one unit?
2. **Instrument** — how is it measured: count, rate, duration, rating scale, coded judgment?
3. **Threshold** — what value separates present from absent, and who set it?
4. **Source** — where do the numbers come from, and could that source be gamed?
5. **Baseline / window** — compared with what, over what period?
6. **Inter-rater agreement** — would two observers code the same case the same way?
7. **Disconfirming observation** — what would count as evidence *against* X being present?
8. **Goodhart guard** — if someone optimized the indicator directly, what would degrade?

The test step converts the definition into a falsifiable expectation: *if X, then observation Y; Z would count against X.* Without step 7 the definition is descriptive, not testable.

## 3. Paul & Elder: concepts as an element of thought

Paul and Elder's framework analyzes reasoning into **elements of thought**:

- Purpose, question at issue, **information**, interpretation and inference, **concepts**, assumptions, implications and consequences, point of view.

**Concepts** covers the theories, definitions, axioms, laws, principles, and models that structure how information is selected and interpreted. Their diagnostic questions:

- "What is the main concept I am using? Can I explain it?"
- "Do I understand the concept well enough to use it accurately?"
- "Am I using a concept that is appropriate to this question, or importing one from another domain?"
- "What alternative concepts could frame this question, and what would each reveal?"

They pair concepts with **intellectual standards** — clarity, accuracy, precision, relevance, depth, breadth, logic, significance, fairness. Clarity and precision are the entry standards: an unclear concept defeats every other standard. A concept is *precise* when it discriminates the cases the reasoning needs; precision beyond the decision's needs is waste, which is why the guardrail "name the stakes" exists.

Two further Paul–Elder affordances:

- **Concept check**: paraphrase the definition in your own words and give an example and a non-example.
- **Alternative concepts**: name a rival definition (e.g., engagement as affect vs. behavior vs. economic value) and ask what each would change in the conclusion.

## 4. Ennis: definition and ambiguity

Robert Ennis's critical-thinking taxonomy treats **clarifying meaning** as a foundational ability, alongside judging credibility and judging inference. Relevant sub-abilities:

- Identify the **issue** and the **conclusion**; find the **reasons**.
- Handle **vagueness** and **ambiguity**: equivocation, amphiboly, accent, reification.
- Judge **definitional adequacy** using the too-broad / too-narrow / circular / emotive criteria above.
- Distinguish **stipulative** from **reportive** definitions, and "definition in use" (meaning fixed by how a term functions in a practice) from explicit definition.
- Detect **persuasive definition** — the classic account is Stevenson's, and Ennis's criteria flag emotive loading as a defect.

Ennis's emphasis on **reasonable judgment in context** is the corrective to elenchus's adversarial streak: a definition is adequate relative to a purpose and a body of cases, not absolutely.

## 5. Techniques and thought experiments

- **Counterexample**: the workhorse. A single clean counterexample defeats a universal definition; a cluster is needed against a statistical or prototypical one.
- **Thought experiment**: construct an idealized case that isolates one variable (e.g., a brain in a vat for "experience"; a perfectly fair lottery for "desert"). Useful when real cases are confounded.
- **Boundary case**: the case nearest the disputed line; its value is that it forces the criterion into words.
- **Scalar / continuum test**: many contested terms (engagement, fairness, risk) are matters of degree. Ask where the threshold sits and whether the threshold is principled or arbitrary.
- **Family resemblance check** (Wittgenstein): if no single feature is shared by all cases but overlapping similarities are, a classical definition will fail. Then specify the *purpose-relative* criterion or the operational threshold instead of forcing necessary and sufficient conditions.
- **Conceptual analysis by cases**: build a 3-column table — case, verdict (X / not-X / unsure), reason. The unsure rows are where the work is.

## 6. Worked examples

### Example A — "engagement" (product context)

- **Initial**: "Engagement means users like the product."
- **Type**: ostensive/mental-state; not checkable.
- **False positive**: A user opens the app daily only because a push notification hijacks attention, and reports disliking it. Definition says engaged (they use it, presumably "like" it); verdict: engaged by usage but not by stated attitude — the definition silently conflates *liking* with *using*, which come apart.
- **False negative**: A user who loves the product but is on parental leave and cannot use it for six weeks. Likes it; not using it. Engagement as a behavioral measure says no; as an attitude measure says yes.
- **Boundary**: A user who uses it heavily for one week to finish a project, then stops. Delight or churn? The definition has no time window.
- **Revision (split)**: Engagement₁ = *attitudinal*: self-reported willingness to recommend and stated importance. Engagement₂ = *behavioral*: frequency and depth of voluntary use in a 30-day window. The original argument ("engagement is up") now must say which one.
- **Operational**: Engagement₂ = number of distinct days with ≥1 core action per active user per 30 days; source = product telemetry; present when ≥8 days and trend beats the prior 90-day baseline.
- **Test**: if behavioral engagement genuinely rose, depth of core actions should rise too, and voluntary (non-notification-driven) sessions should rise; a rise in notification-driven opens with flat voluntary sessions counts against the claim.
- **Goodhart guard**: if the team is rewarded on daily opens, notification volume will rise — measure voluntary sessions and post-hoc satisfaction alongside.

### Example B — "fair" (hiring)

- **Initial**: "A fair process is one where everyone gets the same chance."
- **Type**: reportive but underspecified; "same chance" hides the reference class.
- **False positive**: A lottery among all applicants gives literally equal chances but ignores job-relevant qualification, so it is equal and unjust. Definition admits a clear non-case of a fair *hiring* process.
- **False negative**: Structured interviews with identical questions, plus accommodations for a disabled candidate, give unequal treatment but a fairer process. Definition excludes it.
- **Boundary**: Same interviewers for all candidates vs. different trained interviewers per panel. Same treatment? Same chance?
- **Revision**: A fair hiring process is one whose *criteria are job-relevant and applied consistently*, with *accommodations that remove irrelevant barriers*; equal treatment is instrumental, not the criterion.
- **Operational**: proportion of the decision explained by job-relevant, pre-registered criteria; adverse-impact ratio by group ≥ 0.8 (four-fifths rule) on each stage; source = stage-level applicant data; baseline = prior two cycles.
- **Test**: if the process is fair in the revised sense, stage-level adverse impact should be stable or improving while job-relevant criterion validity is maintained. Rising pass rates with no criterion validity would count against.
- **Guardrail in action**: the parties may discover they agree on all cases and differ only on whether "fair" should mean equal treatment or relevant criteria — a verbal dispute about a word, not a substantive one. Naming that ends the argument faster than another round of probes.
